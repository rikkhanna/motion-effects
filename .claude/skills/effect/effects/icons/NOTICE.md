# Logo files

Card faces for `faces: "devops"` in circular_ring. Copied from the docs of github.com/gruntwork-io/terratest
(`docs/assets/img/logos/`, found in the local Go module cache); `opa.png` was downscaled to 600px wide.

These are the trademarks of their owners (Amazon, Microsoft, Google, Docker, The Linux Foundation, HashiCorp,
GitHub, Gruntwork, Open Policy Agent). Referring to the tools in a video is normal use, but check each
owner's brand guidelines before using them commercially. To use other logos, drop `<name>.png` (transparent PNG,
wide wordmarks work best) in this folder and list the names in the effect's `faces` param.
